# Pumila-ka-Bes
A repository dedicated to serve as a practice field in programming data structure. Queue using doubly linked list will be implemented. This project is for recreational purposes only.

The content of this project was inspired by a 24/7 convenience store, but the program uses 10:00 PM as the default shopping time. Due to the late hour, customers under the age of 18 are prohibited, while those of legal age are permitted. All transaction amounts are stored in a database and displayed under the Gross Revenue option, sorted in ascending order.
